# v2v-rewrite 改动记录

每改一次改写规范，在这里记一条：改了什么、为什么。版本号写在 `SKILL.md` 顶部。

次版本（2.0 → 2.1）= 改写规范变化；主版本 = `gendesk v2v` 读写格式变化，那种改动要和
`src-tauri/src/v2v/rewrite.rs` 一起改。

---

## 2.0 — 2026-11-09

**交接目录下线，改用 CLI。**

GenDesk 不再物化 `v2v/待改写`、不再监听 `v2v/已改写`。读队列用 `gendesk v2v pending`，
写回用 `gendesk v2v rewrite --file`；回写条目格式（`id` + `videoPrompt` 及可选参数）不变。
改写规范本身没有变化。

## 1.1 — 2026-07-29

**景别保持首帧的景别，不再向产品推近。**

产品在画面里被放大多少，即梦就要重绘多少像素，而它对卡套图案与扣环的结构记忆很弱，
放大即改样。运镜收敛到官方词表里的「移」，落幅景别一律等于起幅。

- 「动静分层」的机位一项、成稿结构第 3 段的示范用词，从「极缓推近」改为「极缓平移」。
- 新增一节「景别保持首帧的景别」；约束段追加「景别与首帧一致」。
- 范例二原本是推近版，改写成镜头固定、只让光斑动。
- 反面清单里把「堆运镜」的例子换掉，另加一条「把产品拍大」。

## 1.0 — 2026-07-25

起始版本（`3d62cd3` 建，`d53e0d1` 按即梦官方指南重写规范）。确立：交接目录往返流程、
回写 `rewrite.jsonl` 格式、动静分层（场景可动 / 产品锁死并逐项点名配件）、
手机随手拍观感、不切镜、150–250 字四段成稿结构。
