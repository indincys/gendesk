# Poster 图片接入

GenDesk 适配 Poster 的通用 `poster.images/1` CLI（`export-image-products` / `import-images`），不写对方 SQLite。Poster 不保存明星名单或生成工具约定；其接口规范在 Poster 项目的 `docs/协作规范/图片库CLI接入规范.md`。

## 使用

设置 › 审稿后自动化 › **自动导入 Poster**，默认关闭，手动打开。打开后：

1. 审图页每次「通过」（单张、所选或本组）登记成一个 Poster 批次，审稿结束即在后台导入，**不弹窗、不确认**，不拉起 Poster 界面、不自动发布。
2. 图片按款式进入 Poster 对应商品的图片库存；在 Poster 的商品「图片」页选图、新建图文。
3. 同时打开「自动转实况图」时，批次先等本批实况图配对落盘（JPG + MOV），再连同视频一起导入；某张实况转换失败则批次标「需处理」并写明原因，不会只导一半。实况导入要求 Poster 声明 `live-photo` 能力，旧版 Poster 会明确报错。

关闭开关只暂停新批次与后台导入，已导入图片和已有记录保留。升级前遗留的「待确认」批次在 0050 迁移时一律标为跳过，不会被自动导入。

## 归属

- 每个 `(sku, style)` 解析成 Poster 商品 ID 的顺序：已保存的绑定 → 20 位明星的完整「姓名日历（2027）」唯一匹配。新工单的 sku 为空时取 `organization.product`，即 `(产品, 款式)`。明星身份来自 sku 的完整别名（`姓名日历`、`姓名日历（2027）`、`calendar-2027-拼音`），或产品为 `2027明星日历`（兼容旧写法 `明星日历2027`）时款式正好是 `姓名` / `姓名款`。不从图片文件名或数字 SKU 猜身份，不按前缀或模糊匹配（`谢霆锋演唱会款` 需绑定一次）、不新建商品。
- **投单前就检查**：开启自动导入时，`gendesk submit` 收录前按同一规则检查每个款式，对不上就让工单停在待确认、不生图；Agent 在用户确认商品后用 `gendesk poster bind` 保存绑定再 confirm。读不到 Poster 时不拦单。
- 解析不出的款式让整批停在「需处理」，原因写进批次。设置页「指定商品」或 `gendesk poster bind` 选一次即保存绑定并开始导入，同款其他「需处理」批次一并续导，之后同款自动导入；也可「不导入」结束这一批（不影响已通过的审稿）。
- 绑定存的是商品 ID：商品改显示名仍沿用；原商品被删时不自动认领同名新商品。
- 图片里的人是否正确由人工审稿确认，元数据匹配不能代替看图。

## 文件与恢复

- Poster 直接引用作品目录里的成品（实况则引用 `成品/实况照片` 下的 JPG 与 MOV），不另建副本；已导入的成品请保留原文件。找不到作品成品的旧记录才复制进应用数据目录的 `Poster图片库`。
- 请求使用持久化的来源实例 ID 与作品 UID，首次发送前冻结请求内容；对方已入库但回执中断时，原样重试不会重复加图。
- 失败批次保留原因，设置页可「重试」，应用启动时也会补一轮；不会自动循环重试。
- Poster 回执 `imported / updated / duplicate / deleted` 分别是新增、更新、已存在、用户已删除；已删除的图不会因重试复活。

## 补导历史成品

自动导入关闭期间（或功能上线前）通过的作品从未登记批次。`gendesk poster backfill` 先预演，列出每个款式可补的张数、成品文件已不在的张数和对应商品；`--apply` 只为能对上商品的款式建批（每批最多 50 张）并在后台导入，需先开启自动导入。对不上的款式绑定后再跑一次即可；已导入、待处理或选了「不导入」的作品都不会被重复登记。只补静态图：实况配对完成后队列记录即删除，事后无法可靠找回。

## 实现边界

Rust `poster/` 负责设置、商品解析、绑定、批次台账（0046、0050）、交付与 `backfill` 补导；`intake/ingest.rs` 经 `PosterGate` 在投单时检查归属；`control.rs` 的 `poster.resolve / bind / backfill` 供 CLI 使用；`commands/poster.rs` 提供类型化 IPC；`commands/review.rs` 在验收时登记批次，`live_photo.rs` 配对完成后回填实况文件并唤醒交付。前端只镜像状态并收集「指定商品」的选择，不判定是否入库。

设置中的 Poster 路径指向已安装应用的 `Contents/MacOS/Poster`，调用不经过 shell。
