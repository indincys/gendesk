# GenDesk V1 · 设计 Token 交付

> 与原型 `GenDesk 图片生产工具.dc.html` 一一对应，可直接映射为 Tailwind CSS 4 变量（`@theme`）。色彩全部使用 oklch，浅色主题。

## 1. 颜色

### 表面（中性冷灰，hue 255–262）
| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `oklch(96.4% .004 255)` | 窗口底色（导航区所在层） |
| `--panel` | `#fff` → `oklch(99.4% .002 255)` 垂直渐变 | 主工作区面板（浮起层） |
| `--sub` | `oklch(97.9% .003 255)` | 次级底（状态条、弹窗 footer） |
| `--inset` | `oklch(95.1% .005 255)` | 凹陷底（进度槽、图标底、seg 控件） |
| 环境光 | `radial-gradient(1100px 320px at 22% -8%, oklch(98.6% .007 262/.85), transparent)` | 窗口顶部轻微环境光 |

### 文字
`--t1 oklch(27% .018 262)` 主文字 ｜ `--t2 oklch(47% .016 262)` 次级 ｜ `--t3 oklch(62% .014 262)` 辅助/图标

### 分隔线与描边
`--line oklch(32% .02 260/.08)` 柔和分隔 ｜ `--line2 oklch(32% .02 260/.16)` 控件描边

### 强调（Things 3 主题蓝，hue 257 / chroma .17–.18）
`--acc oklch(58% .18 257)` ｜ `--acc2 oklch(48% .17 257)`（文字/按下） ｜ `--accbg /.1`（选中底） ｜ `--accbg2 /.18` ｜ `--accln /.45`（focus/选中描边）

### 状态（同一明度/彩度带，仅变 hue）
| 语义 | 值 | 底色 |
|---|---|---|
| 成功/已通过 | `oklch(55% .1 155)` | `/.11` |
| 待验收/警示 | `oklch(58% .11 75)` | `oklch(70% .13 80/.15)` |
| 失败/危险 | `oklch(54% .15 25)` | `/.09` |
| 生成中/重试中 | 同 `--acc` | `--accbg` |
| 待处理/未通过 | `--t2` on `--inset` | — |

8 态→5 视觉组映射：待生成=灰；生成中+重试中=蓝(spinner)；失败=红；成功+待验收=琥珀；已通过=绿 / 未通过=灰。

## 2. 圆角
`4/5px` 小标签(kbd/chip) · `6–7px` 徽章/小按钮/缩略图 · `8px` 按钮/输入框/导航项 · `9–10px` 卡片图/横幅 · `11–12px` 卡片 · `13px` 主面板/弹窗/抽屉 · `99px` 胶囊/进度/开关

## 3. 间距（4px 栅格）
`4 6 8 10 12 14 16 18 24`；页面内边距 `18px`，居中栏 max-width `860px`（设置页 `720px`）；表格行高 `40px`（紧凑 `35px`）、提示词行 `32px`、导航项 `29px`、页头 `50px`、标题栏 `44px`、侧栏宽 `212px`。

## 4. 字号阶梯
系统栈：`-apple-system / SF Pro Text / Segoe UI Variable / PingFang SC / Microsoft YaHei UI`；等宽（编号/路径/数字）：`SF Mono / Cascadia Code / Consolas`。
`10.5px` 分区标签(letter-spacing .05–.07em) · `11px` 辅助 · `12–12.5px` 正文/控件 · `13px` 基础 · `14px` 页面标题 · 提示词原文 `12.5px/1.85`，可选中复制。字重仅 400/500/600。

## 5. 阴影（多层级景深）
- L1 控件：`0 1px 2px oklch(20% .02 260/.06)`
- L2 面板/卡片悬停：`0 1px 2px …/.04, 0 3px 14px …/.05`
- L3 弹窗/抽屉/toast：`0 2px 8px …/.07, 0 20px 60px oklch(24% .03 262/.18)`
- 主按钮：蓝投影 `0 1px 2px oklch(42% .16 257/.45)` + 顶部 1px 内高光

## 6. 动效（Motion 实现，全部尊重 prefers-reduced-motion）
- hover/选中过渡 `100–150ms`；弹窗 `pop 180ms cubic-bezier(.2,.9,.3,1)`（scale .97 + 6px 上移）；抽屉右滑 `200ms`；toast 上浮 `220ms`
- 进度条宽度 `300ms ease`，匹配后端 250ms 节流的离散更新
- 生成中 spinner `800ms linear`；未挂靠参考图的引导脉冲 `1.5s ×2` 后静止为琥珀描边

## 7. 关键交互约定
- 键盘：`⌘/Ctrl+K` 命令面板，`⌘1–8` 切页；验收大图 `←/→` 切换、`⏎` 通过、`⌫` 不通过、`R` 微调重试
- Key 状态条默认折叠低对比；出现 Auth 失效时升级为红色徽章 + 行内「停用该 Key」动作
- 错误分级：Auth(红/需人工) > ContentPolicy(红/改词) > Interrupted(琥珀/一键重试) > Timeout/RateLimited(自动重试，弱提示)
- 500 字提示词一律进详情弹窗/侧栏阅读（宽 ≥340px，行高 1.85），列表只显示编号+摘要
