# 提示词 skill 标准产出规范

适用 GenDesk 0.36.1。完整字段、示例、参数表、回执与恢复规则统一维护在 [命令行生图接入](命令行生图接入.md)，本文件只规定提示词 skill 的交付边界，不再复制整份接口规范。

## 产出

- 每张图一份 UTF-8 纯正文 TXT；批量另写 JSON 清单，显式关联 promptFile 和 ref 或有序 refs。正文不混路径说明、SKU、标题或分析。
- 清单顶层或条目填写 organization（产品、款式、需求、来源），同需求持续沿用同名；没有 SKU 不编造编号。条目归属整对象覆盖顶层，完整规则读接入规范。
- 生图参数写清单，默认 quality=high；比例和尺寸不能只写正文。多参考图顺序与 Image 1、Image 2 的描述一致，不合成接触表。
- 按当前项目文件管理约定将提示词、人读说明和清单放入 _草稿；原素材只引用，不搬动。不要向收件目录写普通草稿，因为 READY 会触发生成。

## 收尾

用户只要求写词、研究或本地检查时，交付文件并可运行 validate，**不投单**。用户要求生图或明确授权续做时，先检查 gendesk --version / doctor 与需要的应用能力，再执行：

```bash
gendesk validate --manifest /绝对路径/场景任务.json
gendesk submit --manifest /绝对路径/场景任务.json --open --wait 30
gendesk status cli-返回的工单编号
```

validate 复用应用 Rust 只读入口，完整校验文件、正文、参数、归属与实际图片解码，不投递、不生图；缺少能力时停止并保留输入，不降级成文件预检。回执 ingested 只表示收录建批；生成结果在 GenDesk 人工验收。超阈值需用户确认，不绕过。超时或失败查原 ID、保留回执，不换随机 ID 重投。0.36.1 新单的应用内重试沿原身份检查点只补未完成步骤，不会整单重新导入；已有导入后不得修改原内容。没有检查点的历史部分导入或中断单按主规范核对，不能盲目重放。

新写或更新 prompts-* skill 时引用本文件和接入规范，**不再抄一份打包脚本或字段表**，避免下一次升级留下多份冲突规则。skill 前缀不代表生成授权。无 CLI 的兼容打包方式只在接入规范的对应章节维护。
